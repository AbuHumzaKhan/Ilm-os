# Ilm-os

> **An open-source Learning OS for learning professional and technical skills through structured, practical, interactive education.**

Ilm-os is built around one core idea:

**One Learning Engine + 50+ Skill Libraries.**

The platform is intended to teach skills such as Excel, SQL, Python, Data Analytics, Business Analysis, Git & GitHub, Data Modeling, Power BI, Statistics, Web Development, and many more through structured lessons, practical exercises, real-world projects, assessments, AI-assisted tutoring, and mastery tracking.

## Vision

Ilm-os should feel less like a chatbot and more like a professional learning environment.

A learner should be able to write:

> Teach me VLOOKUP

and receive a structured learning experience covering prerequisites, concepts, examples, guided practice, independent practice, questions, assessment, real-world application, and mastery.

## Development Philosophy

Ilm-os will be developed incrementally. We will not build 50 shallow courses first.

The first objective is to build **one strong, reusable Learning Engine** and prove it with a complete skill experience. Once the engine is reliable, additional skill libraries can be added without redesigning the platform.
