# Security Policy

## Scope

Security issues affecting Ilm-os code, infrastructure, authentication, authorization, data handling, or learner privacy should be reported responsibly.

## Reporting

Do not publish sensitive vulnerability details in a public issue before they have been reviewed.

Use the repository's available private security reporting mechanism when one is enabled. If it is not enabled, contact the project maintainer privately through the contact method listed on the maintainer's GitHub profile.

## Principles

Ilm-os should minimize collection of learner data, protect stored learner information, validate untrusted input, and avoid exposing secrets through source code, logs, or client-side configuration.
