# Ilm-os Mind

## Purpose

Ilm-os exists to make structured, practical, high-quality skill learning accessible to everyone.

## Core Belief

Learning should not depend on randomly searching videos, reading disconnected articles, or asking an AI the same question repeatedly.

A strong learning system should understand:

1. What the learner wants to learn.
2. What the learner already knows.
3. What prerequisites are missing.
4. What should be taught next.
5. Whether the learner can actually apply the concept.
6. Where the learner is making mistakes.
7. When a concept should be reviewed.

## Teaching Philosophy

Ilm-os follows these principles:

- Teach concepts before asking for complex application.
- Explain why a skill exists, not only how to use it.
- Prefer real-world examples over artificial toy examples.
- Make learners practice rather than passively read.
- Give hints before immediately revealing solutions.
- Explain mistakes and their causes.
- Connect related concepts across tools and domains.
- Assess practical ability, not only memorization.
- Track mastery over time.
- Keep the learner in control of the learning path.

## Product Principle

Ilm-os is not intended to be a generic chatbot with educational prompts attached. It is a learning system with an AI tutor as one component.

## Quality Standard

Every skill added to Ilm-os should eventually have:

- prerequisites
- learning objectives
- structured lessons
- examples
- guided practice
- independent practice
- common mistakes
- assessment
- real-world application
- progression/mastery criteria

## Open Source Mission

The project is intended to remain free and open source so that the learning system and its educational infrastructure can be improved by the community.
